Installer Depann'Home Pro

Une application web installable (PWA), sans fichier APK ni passage obligatoire par une boutique. L’installation reste à confirmer sur votre téléphone.

Si votre navigateur ne propose pas l’installation, ouvrez l’application, connectez-vous et faites autoriser votre appareil, puis réessayez depuis le menu du navigateur.

Ouvrir l’application / Se connecter

Suivez les étapes correspondant à votre téléphone ci-dessous.

Ajouter l’application à l’écran d’accueil

Si ce guide s’est ouvert dans votre application e-mail, utilisez son menu pour ouvrir le lien dans le navigateur du téléphone.

Android

  1. Ouvrez ce guide dans Chrome.
  2. Touchez Installer l’application si le bouton est proposé. Sinon, ouvrez le menu ⋮ de Chrome puis Installer l’application ou Ajouter à l’écran d’accueil.
  3. Confirmez l’installation ou l’ajout.
  4. Ouvrez l’icône Depann'Home Pro et connectez-vous.

iPhone / iPad

  1. Ouvrez ce guide dans Safari.
  2. Ouvrez le menu Partager, puis Sur l’écran d’accueil (ou Ajouter à l’écran d’accueil).
  3. Activez Ouvrir comme app web si cette option est proposée, puis touchez Ajouter.
  4. Ouvrez l’icône Depann'Home Pro et connectez-vous.

Votre première connexion

Utilisez l’identifiant reçu par e-mail et le mot de passe initial communiqué séparément par votre administrateur. Aucun mot de passe n’est envoyé dans l’e-mail d’accueil.

L’entreprise doit autoriser votre appareil. Confirmez ensuite le code reçu par e-mail lorsque l’application le demande. Installer l’application ne valide pas l’appareil et ne crée pas un nouvel accès.

À savoir sur la localisation

Le partage de position est volontaire et peut être arrêté. La PWA actuelle ne garantit pas la géolocalisation lorsque le téléphone suspend l’application, lorsque l’écran est éteint ou lorsque l’application est fermée.
